# 🍳 PlateRank — Cook. Rank. Brag.

> A gamified cooking app where home cooks track ingredients, match recipes, complete weekly challenges, level up, and compete in friendly Kitchen Food Fights.

## 🚀 Getting Started
1. Extract `platerank.zip`.
2. Open `index.html` in any web browser.

## ✨ Key Features
* 🥕 **Weekly Ingredient Challenges**: Submit dishes incorporating featured ingredients ("Carrot Clash").
* 🛒 **Pantry Autocomplete & Matcher**: Predictive ingredient search with auto-correct and substitution weight calculations (~93% math).
* ⚔️ **Kitchens & Food Fights**: Join clan kitchens and battle rival teams in real-time simulated score matches.
* 🏆 **Brag Board Leaderboards**: Diet-filtered ladders (Omnivore, Vegetarian, Vegan, Gluten-Free).
* 👨‍🍳 **Chef Progression**: XP, levels, and unlockable achievement badges stored in LocalStorage.
* 🌓 **Dark / Light Mode**: High-contrast theme toggle with stored preferences.

## 🛠️ Tech Stack
* HTML5 / Vanilla ES6 JavaScript
* Tailwind CSS (CDN)
* FontAwesome 6 (CDN)
* LocalStorage API
